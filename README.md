# PySpark Basics 🚀

A hands-on repository for learning and practicing **PySpark** concepts from the ground up. This repository contains examples, exercises, and notes covering the core building blocks of Apache Spark using Python.

## 📌 About

This repository is my personal learning journey through PySpark. The goal is to understand distributed data processing by implementing concepts through practical examples rather than just reading documentation.

Topics range from basic DataFrame operations to transformations, actions, Spark SQL, and performance optimization techniques.

---

## 🛠 Tech Stack

- Python 3.x
- Apache Spark (PySpark)
-  Notebook / VS Code
- Git & GitHub

## 🎯 Purpose

The purpose of this repository is to:
